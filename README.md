# VeloIreland - Cycling Route Guide

An Angular + PrimeNG app for showcasing cycling routes, deployable on GitHub Pages and as a native Android or iOS app with Capacitor.

> This file is generated by `python update_readme.py`. Run `npm run readme:update` after changing route data, or use the npm scripts below that do it automatically.

## Features

- Dynamic JSON content loaded from `public/routes.json`
- Route data generated from GPX files in `src/assets/gpx_files`
- Long Routes / Short Routes tabs
- Route cards with map image, elevation profile, distance, ascent, max altitude, description, and expanded details
- Responsive layout using Angular and PrimeNG

## Updating Routes And README

Add or edit GPX files in:

- `src/assets/gpx_files/longRoutes`
- `src/assets/gpx_files/shortRoutes`

Then run:

```bash
npm run routes:update
```

That command refreshes `public/routes.json` and regenerates this README. To preview route changes without writing JSON:

```bash
npm run routes:preview
```

To only refresh the README:

```bash
npm run readme:update
```

To generate missing route descriptions with OpenAI, create a local `.env` file in the project root:

```bash
OPENAI_API_KEY=sk-your-key-here
```

Then run:

```bash
npm run routes:update:copy
```

## Native Android And iOS Apps

After cloning the project, install dependencies once:

```bash
npm install
```

Create the platform projects once (iOS requires macOS with Xcode):

```bash
npm run cap:add:android
npm run cap:add:ios
```

For every web-app change, sync the production build into the native projects:

```bash
npm run cap:sync
```

Then open the platform project to run it on an emulator or a connected device:

```bash
npm run cap:android
npm run cap:ios
```

The `android/` and `ios/` folders are source-controlled native projects. Use Android Studio for Android builds and Xcode on macOS for iOS signing, builds, and App Store submission.

### Build And Install A Debug APK On Windows

This project compiles Java 21 source code. Install a JDK 21 and configure Android Studio to use it at **Settings -> Build, Execution, Deployment -> Build Tools -> Gradle -> Gradle JDK**. Select a Java 21 JDK, not Java 11 or 17.

For command-line builds, use the same JDK in the current Command Prompt window. Replace the example path if your JDK is installed elsewhere:

```cmd
cd /d G:\Git\cycling-routes\android
set "JAVA_HOME=C:\Users\<your-user>\.jdks\ms-21.0.12.1"
set "PATH=%JAVA_HOME%\bin;%PATH%"

java -version
gradlew.bat --stop
gradlew.bat assembleDebug
```

`java -version` must report version 21 before building. If Android Studio installed the JDK, locate it with:

```cmd
dir "%USERPROFILE%\.jdks"
```

After a successful build, the APK is at:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Copy it to an Android phone and open it to install, allowing the file manager to install unknown apps when Android asks. With USB debugging enabled, it can also be installed directly:

```cmd
adb install -r android\app\build\outputs\apk\debug\app-debug.apk
```

### Updating A Native Build

After every change to the Angular app, first copy the new web build and Capacitor plugins into the native project:

```cmd
cd /d G:\Git\cycling-routes
npm run cap:sync
```

Then rebuild the APK using the Java 21 commands above. The GPX download feature uses Capacitor's native file and share integrations, so `npm run cap:sync` is required before testing it on Android or iOS. On a phone, tapping **Download GPX** opens the native save/share chooser; select Files or a compatible GPX app.

## Deploy To GitHub Pages

```bash
npm run deploy
```

The deploy workflow builds the GitHub Pages version and publishes `dist/cycling-routes/browser` to the `gh-pages` branch. Run `npm run routes:update` or `npm run readme:update` first if route data or documentation needs refreshing.

After the first deploy, go to **Settings -> Pages -> Branch: gh-pages -> Save**.

If GitHub Pages keeps serving an older version after a successful deploy, force a fresh `gh-pages` commit:

```bash
npx gh-pages -d dist/cycling-routes/browser --message "Force GitHub Pages redeploy"
```

Then wait a minute and check `https://<username>.github.io/<repo-name>/routes.json`.

Your site URL will be:

```text
https://<username>.github.io/<repo-name>/
```
